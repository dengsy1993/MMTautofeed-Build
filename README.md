## 一、直接使用（推荐新手）

到本仓库的 **Actions 产物 / Releases** 里下载对应平台的压缩包：

- Windows：下载 `MMTautofeed_Windows_Package` 里的 `MMTautofeed.exe`，双击即可运行；
- macOS：下载 `MMTautofeed_MacOS_Package` 里的 `MMTautofeed.app`，首次打开若被系统拦截，右键 ➔ 打开，或到「系统设置 ➔ 隐私与安全性」里允许。

> 打包版已经内置所有依赖，**不需要**自己装 Python。

## 二、从源码运行

### 💻 Windows

1. 安装 Python（3.10 及以上）：<https://www.python.org/downloads/>
   - **务必勾选安装界面的 `Add python.exe to PATH`**。
2. 打开命令提示符（`Win + R` 输入 `cmd` 回车），安装依赖：
   ```cmd
   pip install PyQt6 requests torf qbittorrent-api
   ```
   下载慢可加清华源：
   ```cmd
   pip install PyQt6 requests torf qbittorrent-api -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
3. 运行：
   ```cmd
   python MMTautofeed.py
   ```
   （在资源文件夹地址栏输入 `cmd` 回车，再执行上面这句也可以。**注意文件名是 `MMTautofeed.py`**。）

### 🍎 macOS

1. 安装 Python（推荐 Homebrew）：
   ```bash
   brew install python
   ```
2. 安装依赖：
   ```bash
   pip3 install PyQt6 requests torf qbittorrent-api
   # 慢的话：
   # pip3 install PyQt6 requests torf qbittorrent-api -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```
3. 运行（在源码目录下）：
   ```bash
   python3 MMTautofeed.py
   ```

## 三、首次配置（偏好设置）

打开软件后，点顶部 **【⚙️ 偏好设置】**，逐项填好，最后点 **【💾 保存偏好设置】**。

### 1. 基础路径
- **官方种子存放位置**：推荐 `./torrents`。程序会自动建立两个子文件夹：
  - `Local_Made`：你自己本地生成的原始种子；
  - `PT_Official`：发种成功后从 PT 站拉回来的、带 Passkey 的官方种子（隔离存放，避免误用）。
- **做种文件位置**：推荐 `./seeding`。打包好的 ZIP / 待做种内容放在这里。

> 相对路径（如 `./torrents`）在打包版里：Windows 相对于程序所在目录；macOS 相对于你的用户主目录（`~/torrents`）。

### 2. PT 站点与图床
- **PT 站域名**：例如 `https://www.momentpt.top/`，**结尾要带斜杠**。
- **账号 Cookie**：发种的通行证。获取方法：
  1. 浏览器登录 PT 站 ➔ 按 `F12` 打开开发者工具 ➔ 切到 **Network（网络）** ➔ 刷新页面；
  2. 点任意一个请求 ➔ 右侧 **Request Headers** ➔ 找到 `Cookie:`，把整行内容完整复制；
  3. 粘贴到「账号 Cookie」。（要包含登录态字段，缺了会被当成未登录。）
- **图床**：默认已填好 MomentPT 图床 API。填入邮箱/密码后点 **【向图床申请获取 Token】**，成功会自动填入 Token。
- **发种限流保护**：默认 3 秒。批量连发时适当的间隔可以避开站点防刷。

### 3. qBittorrent 联动
- 填 qB 面板地址（默认 `http://127.0.0.1:8080`）、WebUI 账号密码；
- 勾选 **【将种子自动推送到 qBittorrent 并强制开启做种】**。发种成功后会自动把带 Passkey 的官方种子推给 qB 并开始做种。

### 4. 名称解析模式
决定“文件夹名 ➔ 最终种子标题”的转换方式：
- **禁用提取**：不改动，直接用文件夹名（适合已手动规整好名字的情况）。
- **简单提取（推荐）**：把完整文件夹名作为『主题』，自动补年份和 P 数，其余用预设补齐。
  - 例：`海边漫步` ➔ `『海边漫步』-预设模特-预设摄影师-2023-36P-Moment`
- **强效重组（高阶）**：智能识别文件夹名中的模特/摄影师/日期并剔除，再按标准格式重组。
  - 例：`MintYe薄荷叶 2021.02.28 Vol.004 何梦兮Stacy` ➔ `『MintYe薄荷叶 Vol.004』-何梦兮Stacy-2021-63P-Moment`

> 不确定效果时，可先去 **【🧪 名称解析沙盒】** 预览，不影响正式流程。

### 5. 广告文件拦截器
很多资源夹混有引流用的 `.url`、`.txt` 或赌博网址。在输入框输入要拦截的**文字或后缀**，按 **回车** 加入黑名单；智能扫描时会自动把这些文件清理掉。

### 6. 网络代理 / 复用开关（新增）
见下方 [五、网络代理](#五网络代理vpn-用户必看)。另有 **【复用已存在的 ZIP/种子】** 开关（默认关闭），勾选后内容未变时跳过重复打包制种，提速。

## 四、批量发种三步走

切到 **【⚡ 批量上传流水线】**，这是日常主界面。

### 第一步：选预设
- 确保顶部「发布预设」下拉框选中了本次要用的模板；
- 点 **【⚙ 管理预设】** 可新增/编辑/复制模板。

### 第二步：加文件夹 + 扫描
1. **【📁 1.添加文件夹】**：批量导入资源文件夹（可多选）。
2. **【🔍 2.智能扫描提取】**：自动清理拦截文件、统计 P/V 数、提取年份、生成最终标题（显示在“最终种子名称”列）。
3. 表格里任何一格都可以**双击手动修改**；选错行点 **【➖ 移除选中行】**。
4. **【🔄 3.序列化重命名（可选）】**：把包内文件重命名为 `1.jpg, 2.mp4 …`（**直接改硬盘、不可逆，慎用**）。

### 第三步：封面准备 + 打包发布
- **3.1 封面准备（可选）**：
  - 【🖼️ 自动匹配本地封面】：按资源名去指定文件夹找同名图片；
  - 【📌 为选中行指定封面】：给表格里选中那一行手动指定图片；
  - 【🎨 去【封面拼图台】做四宫格封面】：把多张图拼成一张封面，保存到输出目录；
  - 勾选“全自动时自动使用封面台输出目录的封面”，一键全自动会自动去抓。
- **3.2 分步执行**（想单独重做某一步时用）：
  - 【📦 第1步：打包并制作种子】生成 ZIP 与 `.torrent`；
  - 【🚀 第2步：推送到 PT 站并做种】发布并推送 qB。
- **3.3 一键全自动（推荐新手）**：
  - 点 **【🚀 一键全自动打包发布】**，按 找封面 ➜ 打包制种 ➜ 上传图床 ➜ 发布表单 ➜ 推送 qB 的顺序自动完成；
  - 想中途停止点 **【🛑 停止当前任务】**。

进度和报错都显示在第三步的 **📝 实时进度** 框里，也可以切到 **【🖥️ 运行日志监控】** 看更完整的日志。

## 五、网络代理（VPN 用户必看）

如果你开了 VPN / Clash / v2ray 等代理，PT 站和图床请求可能因路由问题失败。此时：

1. 进入 **【⚙️ 偏好设置 ➔ 🌐 PT站点与图床配置】**；
2. 勾选 **【启用网络代理】**；
3. 填写代理地址，默认 `127.0.0.1:7897`（Clash 常见端口），也支持 `http://host:port` 形式；
4. 保存后，PT 站请求、图床请求、以及设置页的“测试连通性 / 获取 Token”都会走代理。

> **qBittorrent 不走代理**（它在本机，走代理反而连不上）。默认**关闭**代理，不需要时不要勾选。

## 六、常见问题 FAQ

**Q1：日志提示“重定向至登录页，Cookie 失效”？**
A：Cookie 过期或不完整。重新按上文从浏览器 F12 复制**完整** Cookie（含用户身份字段）并保存。若是 VPN 环境，先试试打开网络代理。

**Q2：日志提示“未找到种子文件”“未制作种子”？**
A：先执行 **【3.2 第1步：打包并制作种子】**。程序现在会在发布时自动容错查找，并在缺失时尝试现场补做 ZIP/种子。

**Q3：重复运行报 `File exists`？**
A：已修复：现在会直接覆盖重新生成（内容不变时 infohash 不变，已发布的种子不受影响）。想跳过重复生成，可开启【复用已存在的 ZIP/种子】。

**Q4：缺少 `torf` 库 / `requests` 库？**
A：你的 Python 环境没装依赖。运行 `pip install PyQt6 requests torf qbittorrent-api`。注意要和运行程序用的**同一个** Python。

**Q5：macOS 上找不到报错/配置/日志文件？**
A：打包版会把配置、预设、日志放在 `~/Library/Application Support/MMTautofeed/`，不会写进 `.app` 内部。种子/做种目录按你设置的路径（相对路径默认在主目录下）。

**Q6：macOS 打开 `.app` 时 Dock 出现两个图标？**
A：请使用最新打包产物（已修正打包方式，`--onedir` + 正常的 `LSUIElement=false`）。旧产物可能仍有该问题。

**Q7：提示“未选择分类”？**
A：该行没有选 PT 分类。直接在表格“分类”列选择即可（不再偷偷发到错误板块）。
