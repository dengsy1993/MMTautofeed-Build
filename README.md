## 一、这是什么

一条龙完成「本地文件夹 ➜ PT 站可下载种子」的全部步骤：

- 📦 自动打包 ZIP（**智能压缩**：图片/视频等已压缩格式直接存储，其它文件 Deflate 压缩）、用 `torf` 生成私有种子；
- 🧠 按预设规则把文件夹名智能清洗、组装成规范标题（可预览、可沙盒调试）；
- 🖼️ 自动匹配封面 / 四宫格拼图封面 / 上传图床；
- 🚀 自动组装表单并发布到 PT 站（支持分类、标签、匿名）；
- 📥 发布成功后拉取带个人 Passkey 的官方种子；
- 📡 推送 qBittorrent 并开始做种；
- 🛡️ 发种前自动清理广告文件（`.url`、`.txt`、引流网址等）；
- 🎨 明/暗主题、自定义 CSS、背景图、系统托盘等完整外观与体验。

平台：Windows（`.exe`）、macOS（`.app`）。

## 二、快速开始

### 2.1 Windows（推荐新手）

1. 到仓库的 **Actions 产物 / Releases** 下载 `MMTautofeed_Windows_Package`；
2. 解压得到 **单个** `MMTautofeed.exe`，双击运行（可放任意位置）；
3. 首次打开先做 [三、偏好设置](#三功能区偏好设置先配置一次)。

> 打包版已内置全部依赖，无需安装 Python。
> 说明：单文件 exe 打开时会先自解压，所以启动需要几秒——这是单文件打包的固有机制，与程序本身无关。

### 2.2 macOS

1. 下载 `MMTautofeed_MacOS_Package` 得到 `MMTautofeed.app`；
2. 首次打开若被系统拦截：右键 ➜ 打开，或到「系统设置 ➜ 隐私与安全性」允许；
3. 同样先做偏好设置。

### 2.3 从源码运行（可选）

```bash
pip install PyQt6 requests torf qbittorrent-api
python MMTautofeed.py
```

## 三、功能区：偏好设置（先配置一次）

点顶部 **【⚙️ 偏好设置】**，逐项填好，最后点底部 **【💾 保存偏好设置】**。
（想放弃修改点 **【取消更改，恢复上次保存配置】**。）

本页分多个区块，下面逐块讲。

### 3.1 📌 基础路径设置

- **官方种子存放位置**：推荐 `./torrents`。程序会自动建两个子目录：
  - `Local_Made`：本地自己生成的原始种子；
  - `PT_Official`：发种成功后从站点拉回的、带 Passkey 的官方种子（隔离存放，避免混用）。
- **做种文件位置**：推荐 `./seeding`。打包好的 ZIP / 待做种内容放这里。
- 相对路径的规则：
  - Windows（打包版）：相对于**程序所在目录**；
  - macOS（打包版）：相对于**你的用户主目录**（如 `~/torrents`）。

### 3.2 🌐 PT 站点与图床配置

- **PT站域名**：例如 `https://www.momentpt.top/`，**结尾要带斜杠**；
- **账号 Cookie**：发种的通行证。获取方法：
  1. 浏览器登录 PT 站 ➜ 按 `F12` ➜ 切到 **Network（网络）** ➜ 刷新页面；
  2. 点任一请求 ➜ **Request Headers** ➜ 找到 `Cookie:` 整行复制；
  3. 粘贴进来（必须包含登录态字段，如 `c_secure_uid` / `c_secure_pass`）。
- **测试能否连通 PT 站**：一键验证域名 + Cookie 是否有效。
- **图床**：默认已填好 MomentPT 图床地址。
  - 填邮箱 / 密码 ➜ 点 **【向图床申请获取 Token】** 自动填入 Token；
  - **图床上传失败时重试次数**：默认 5 次；
  - **发种网络失败时重试次数**：默认 5 次（失败等 2 秒再试），与图床重试机制一致；网络抖动/代理断连时会自动重试，避免一次失败就中断发种；
  - **测试图床连通性**：验证图床是否可达。
- **发种限流保护**：每个种子之间的间隔秒数（默认 5 秒，`0` 为不限速）。
- **网络代理**：见 [九、网络代理](#九网络代理vpn-用户)。

### 3.3 🖥️ 窗口与托盘

- **关闭窗口时**：下拉三选一（常规软件做法）：
  - **关闭时询问我**（默认）：点右上角关闭会**弹窗**，让你选择【最小化到系统托盘 / 关闭软件】，弹窗里可勾选 **「记住我的选择，以后不再询问」**（勾了以后就不再弹窗，直接按上次选择执行）；
  - **最小化到系统托盘**：关闭直接收进托盘，任务不中断；
  - **直接退出程序**：关闭即退出。
- **最小化到托盘时弹出提示通知**：默认开；嫌吵可取消勾选。
- 收进托盘后：**单击托盘图标**恢复主窗口；**右键托盘图标 ➜ 退出程序**才彻底退出。

### 3.4 🎨 自定义样式 (CSS/QSS)

Qt 的 QSS 就是 **CSS 语法**，这里可以让界面完全个性化：

1. 点 **【✏️ 编辑样式代码…】** 弹出编辑器；
2. 直接粘贴 / 编写 CSS，或点 **【插入示例】**（一份可自动适配明暗主题的示例）、**【从文件导入】**；
3. 点 **【💾 保存并应用】**，代码会存进 `config.json`，并叠加到内置主题之上。

支持 **`@变量`**，会按当前主题自动替换颜色，例如：

```css
QGroupBox { background-color: @card_bg; }        /* 卡片底色 */
QMainWindow, QDialog {
    background: qlineargradient(x1:0, y1:0, x2:1, y2:1,
        stop:0 @grad1, stop:0.5 @grad4, stop:1 @grad7);
}
```

常用变量：`@bg @surface @surface2 @border @text @text_muted @primary @primary_hover
@success @warning @danger @purple @card_bg @grad1 … @grad7`。
写的属性覆盖内置主题，没写的沿用内置主题。

> 透明度分级（数值越小越透）：输入框 `@field_bg`、卡片 `@card_bg`、对话框 `@dialog_bg`、表格 `@table_bg`。

### 3.5 🖼️ 背景图片

1. 点 **【🖼️ 设置背景图片…】**；
2. 粘贴**图片直链**（图床 / 任意 https 图片）或 **选择本地图片**；
3. 点 **【🔍 预览】** 确认后 **【💾 使用此图】**；
4. 勾选 **启用背景图片** 即生效；点 **【清除】** 可移除。

特点：
- 只保留**一张**背景图文件（`userdata/background.jpg`），方便管理/替换；
- 自动按窗口大小 **cover 铺满**，窗口化 / 最大化切换实时自适应；
- **与自定义 CSS 共存**：背景图在底层，CSS 的渐变会以半透明色膜叠在图上，卡片/按钮/输入框也保持半透明，能看到后面的图与色。

### 3.6 ⚙️ 防误抓拦截规则与自动化配置

- **qB 端口地址 / 账号 / 密码**：默认 `http://127.0.0.1:8080`；
- **qB 下载分类 / 下载标签**：选填；
- **将种子自动推送到 qBittorrent 并强制开启做种**：发种成功后自动把官方种子推给 qB；
- **测试连接 qBittorrent**：一键测试（**5 秒**连不上会直接报错，不会卡住界面）；
- **复用已存在的 ZIP/种子**：内容未变时跳过重新打包/制种，提速（默认关；源文件夹变了记得取消勾选或删旧文件）。

### 3.7 名称解析模式

决定「文件夹名 ➜ 最终种子标题」的转换方式（三选一）：

- **禁用提取**：不改动，直接用文件夹名（适合已手动规整好名字）。
- **简单提取（推荐）**：把完整文件夹名作为『主题』，自动补年份和 P 数，其余用预设补齐。
  例：`海边漫步` ➜ `『海边漫步』-预设模特-预设摄影师-2023-36P-Moment`
- **强效重组（高阶）**：识别文件夹名里的模特/摄影师/日期并剔除，再按标准格式重组。
  例：`MintYe薄荷叶 2021.02.28 Vol.004 何梦兮Stacy` ➜ `『MintYe薄荷叶 Vol.004』-何梦兮Stacy-2021-63P-Moment`

> 不确定效果时，先去 [名称解析沙盒](#五功能区名称解析沙盒) 预览，不影响正式流程。

### 3.8 广告文件拦截器

很多资源夹混有引流文件（`.url`、`.txt`、赌博网址等）。

- 在 **「包含以下文字则删除」** 或 **「属于以下后缀则删除」** 输入框输入内容，按 **回车** 加入拦截库；
- **删除选中 / 全部清空** 管理列表；
- 之后「智能扫描提取」时会自动清理命中文件，并在日志里提示。

### 3.9 保存 / 恢复

- **💾 保存偏好设置**：写入 `userdata/config.json`；
- **取消更改，恢复上次保存配置**：丢弃未保存修改。

## 四、功能区：批量上传流水线（日常主界面）

切到 **【⚡ 批量上传流水线】**，这是每天用的主界面，分三步。

### 第一步：选择发布预设与基础设定

- **发布预设**：选一个模板，决定标题里的摄影/模特、简介、默认分类、默认标签；
- **⚙ 管理预设**：新增 / 编辑 / 删除 / 复制模板（详见弹窗）；
- **刷新**：重新读取预设列表；
- **匿名上传**：发布时不显示发布者（推荐勾选）；
- **打包为ZIP**：把每个资源文件夹压成一个 ZIP 再制种（推荐勾选）；
  - 采用**智能压缩**：`.jpg/.png/.mp4/.mkv` 等已压缩格式直接存储（快、无收益），其余文件用 Deflate 压缩（更小）；
  - 提示：更换压缩参数后，同一资源重新打包会生成不同的种子（infohash 变化），需要重新发布；已发布过的旧种子不受影响。
- **仅测试(不发到PT)**：只演练流程、检查标题/分类/标签，不真正发布、也不推 qB；
- 下方灰色框会显示当前预设的详情，方便核对。

### 第二步：添加资源文件夹并自动提取

1. **【📁 1.添加文件夹】**：批量导入资源文件夹（可多选，Win 按 `Ctrl` / Mac 按 `Command`）；
2. **【🔍 2.智能扫描提取】**：自动清理拦截文件、统计 P/V 数、提取年份、生成最终标题；
3. **【🔄 3.序列化重命名 (可选)】**：把包内文件重命名为 `1.jpg, 2.mp4 …`（**直接改硬盘、不可逆，慎用**）；
4. **【🧪 4.名称解析沙盒(调试)】**：跳到沙盒预览解析效果；
5. **【➖ 移除选中行】/【🗑 清空列表】**：管理待发布列表；
6. **【✅ 清除已完成发种】**：一键移除状态为「发布成功」的行，**保留发布失败 / 未完成的行**，方便只重跑失败项。

表格 12 列：原始文件夹名 / 最终种子名称 / 应用预设 / 锁定 / 物理路径 / P·V数 / 年份 / 分类 / 附加标签 / 种子 / 状态 / 操作。
- **任何一格都能双击修改**（改了标题会按规则自动刷新）；
- **锁定**：勾选后，切换顶部全局预设不会覆盖这一行。

### 第三步：封面准备 ➜ 打包制种 ➜ 发布做种

**3.1 封面准备（可选）**

- **🖼️ 自动匹配本地封面**：按资源名去指定文件夹找同名图片（jpg/jpeg/png）；
- **📌 为选中行指定封面**：先选表格一行，再挑一张图；
- **🎨 去【封面拼图台】做四宫格封面**：跳到封面台制作；
- **全自动时使用封面台输出目录的封面**：勾选后「一键全自动」会先去抓拼好的封面。

**3.2 分步执行（想单独重跑某一步时用）**

- **📦 第1步：打包并制作种子**：生成 ZIP 与 `.torrent`；
- **🚀 第2步：推送到 PT 站并做种**：发布并推送 qB。

**3.3 一键全自动（新手推荐）**

- **【🚀 一键全自动打包发布】**：按 找封面 ➜ 打包制种 ➜ 上传图床 ➜ 发布表单 ➜ 推送 qB 顺序自动完成；
- **【🛑 停止当前任务】**：中断后台任务（建议等当前项处理完再点）；
- 下方 **实时进度** 进度条 + 日志框会显示每一步结果与报错。

## 八、数据与文件位置

所有「属于你的数据」都集中在一个 **`userdata`** 文件夹里，升级程序时只要保留它即可。

> 升级应用版本：直接替换程序本体（exe / app），保留 `userdata/` 与 `logs/` 即可。

## 九、网络代理（VPN 用户）

开了 VPN / Clash / v2ray 时，PT 站和图床请求可能因路由失败：

1. 进 **【⚙️ 偏好设置 ➜ 🌐 PT站点与图床配置】**；
2. 勾选 **【启用网络代理】**；
3. 填代理地址，默认 `127.0.0.1:7897`（Clash 常见端口），也支持 `http://host:port`；
4. 保存后，PT 站请求、图床请求、连通性测试都会走代理。

> **qBittorrent 不走代理**（它在本机）。默认关闭代理，不需要别勾。

## 十、常见问题 FAQ

**Q1：日志提示「重定向至登录页，Cookie 失效」？**
A：Cookie 过期或不完整。重新从浏览器 F12 复制**完整** Cookie（含登录态字段）并保存；VPN 环境先试试打开网络代理。

**Q2：提示「未找到种子文件 / 未制作种子」？**
A：先执行 **第三步 ➜ 第1步：打包并制作种子**。程序也会在发布时自动容错查找、缺失时现场补做。

**Q3：重复运行报 `File exists`？**
A：已修复为直接覆盖重新生成（内容不变 infohash 不变，不影响已发布）。想跳过重复生成，开启【复用已存在的 ZIP/种子】。

**Q4：缺少 `torf` / `requests` 库？**
A：同一 Python 环境执行 `pip install PyQt6 requests torf qbittorrent-api`。

**Q5：测试 qB 连接转圈很久？**
A：已限制 **5 秒**超时并放到后台线程，超时直接报错，界面不会卡。

**Q6：macOS 找不到配置/日志？**
A：打包版在 `~/Library/Application Support/MMTautofeed/`（配置/预设/背景图在 `userdata/`，日志在 `logs/`）。

**Q7：macOS 打开 `.app` 出现两个 Dock 图标？**
A：请使用最新打包产物（已修正 `--onedir` + `LSUIElement=false`）。

**Q8：提示「未选择分类」？**
A：该行没有选分类。回到「批量上传流水线」第二步，在表格「分类」列选择即可（不再偷偷发到错误板块）。

**Q9：想让界面更个性 / 换背景？**
A：偏好设置里有 **🎨 自定义样式(CSS/QSS)** 与 **🖼️ 背景图片**，二者可同时生效。

**Q10：关闭软件后，`.exe` 仍提示被占用，无法覆盖？**
A：已修复。单文件版退出时会先结束后台线程、隐藏托盘，再强制结束进程，立即释放 `.exe` 占用。
（若仍偶发，请在任务管理器确认没有残留的 `MMTautofeed.exe` 再覆盖。）

## 十一、开发者：打包发布

仓库内置 GitHub Actions（在 Actions 页面手动触发 `workflow_dispatch`）：

- `.github/workflows/build_win.yml`：Windows 打包（PyInstaller，**单文件 exe**）
  - `--onefile --windowed --icon "app_icon.ico" --add-data "app_icon.ico;."`
  - `--icon` 设置 exe 文件图标；`--add-data` 让运行期也能读到图标（窗口/任务栏图标完整）；
  - 产物为单个 `MMTautofeed.exe`；
  - 若更在意启动速度，可把 `--onefile` 改为 `--onedir`（产物变文件夹，启动更快）。

产物：
- Windows：`MMTautofeed.exe`
- macOS：`MMTautofeed.app`（压缩为 zip）
