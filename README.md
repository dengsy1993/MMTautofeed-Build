# 🚀 MMTautofeed 批量发种工具 v1.03.6
MMTautofeed 是一款专为 PT (Private Tracker) 玩家打造的全自动化批量发种神器（深度适配 Moment PT 站点）。
它可以帮你彻底告别机械化的“制种、拼封面、传图床、填表单、挂 qB”流程。只需点几下鼠标，剩下的全部交给程序！

# ✨ 核心亮点 (Features)
## 🤖 一键全自动流水线：自动找图/拼图 ➔ 打包(可选ZIP) ➔ 制种 ➔ 推送图床 ➔ 表单发布 ➔ 推送 qBittorrent 做种。

## 🧠 智能名称解析引擎：强大的“强效重组”功能与自定义正则沙盒，自动为你组装最标准、最整齐的种子标题。

## 🖼️ 高级封面拼图台：内置原生拖拽微积分引擎，一键随机抽取 4 张美图拼成极品封面，支持丝滑拖拽与缩放。

## 🛡️ 广告防误抓拦截：自动清理资源包内的垃圾广告、网址文件，向“违规封号”说拜拜。

# 🛠️ 环境依赖与安装 (Installation)
本工具基于 Python 编写，并使用 PyQt6 作为图形界面。

安装 Python 3.8 或以上版本（请确保在安装时勾选了 Add Python to PATH）。

安装核心依赖库。打开电脑的命令提示符 (CMD) 或终端 (Terminal)，运行以下命令：

Bash

```
pip install PyQt6 requests torf qbittorrent-api
```
运行程序：

Bash
```
python MMTautofeed.py
```
# 📖 快速上手指南 (Quick Start)
初次打开软件时，请务必按照以下 三个步骤 完成基础配置，之后即可起飞！

## 第一步：偏好设置 ⚙️
进入软件的 【⚙️ 偏好设置】 标签页，依次填好你的通行证：

### 基础路径：设置你希望保存“官方种子”和“做种文件”的文件夹。

### PT 站配置：填写目标站点的域名，以及你账号的 Cookie（这很重要，用来验证你的身份）。建议点击 [测试能否连通 PT 站] 确保正常。

### 图床配置：填写图床邮箱和密码，点击 [向图床申请获取 Token]。

### qBittorrent 配置：填写 qB 的 IP 端口（例如 http://127.0.0.1:8080）、账号和密码。

进阶玩法：你可以在这里预先填好 qB 下载分类（如 PT）和 qB 下载标签，程序发种后会自动帮你归类。

💡 别忘了点击最下方的 [💾 保存偏好设置]！

## 第二步：建立发布预设 📝
在批量发种前，我们需要告诉程序这批资源属于哪个摄影师、什么分类等。

回到 【⚡ 批量上传流水线】 标签页。

点击上方的 [⚙ 管理预设] 按钮，点击 [十 新增一条预设]。

填入预设名称（如“秀人网通用”），设置好默认的摄影师、模特、统一简介、分类和标签。

保存后，在主界面的下拉菜单中选中你刚才建好的预设。

## 第三步：开始批量发种！🚀
现在进入最激动人心的流水线环节：

### 📁 1.添加文件夹：点击按钮，选中你需要发布的多个资源文件夹（可以按住 Ctrl 多选）。

### 🔍 2.智能扫描提取：程序会自动扫描文件夹内有多少张图(P)和视频(V)，并结合你选的预设，智能组装出标准标题。
(如果发现标题不合心意，可以直接双击表格里的文字手动修改)

### 🖼️ 封面处理 (可选)：你可以点击 [去【封面拼图台】制作高级拼图] 批量生成超赞的九宫格/四宫格封面，或者点击 [手动本地寻图] 让程序自动匹配同名图片。

### 🚀 一键全自动打包发布：点击最下方蓝色大按钮，端起咖啡，看着进度条和日志跑完，你的种子就已经在 PT 站上并开始做种了！

# 🎓 进阶功能揭秘 (Advanced Features)
## 🧪 名称解析沙盒
如果你的原始文件夹名字五花八门，不妨去 【🧪 名称解析沙盒】 调教一下。

### 简单提取：只在你的原标题后加上年份和图片数量。

### 强效重组：自动剔除原标题里的模特、年份，严格按照 『主题』-模特-摄影师-年份-数量-Moment 重组。

### 自定义规则：你可以添加“文本替换”或“正则匹配”，比如把多余的 [完结] 字符删掉（替换为空）。沙盒右侧会实时为你推演替换前后的最终效果！

## 🖼️ 封面拼图台
这就像是一个轻量级的美图秀秀：

### 自动拼图：在左侧导入资源文件夹后，只需单击列表中的文件夹，右侧工作台瞬间为你生成 4 张图的拼接海报！

### 丝滑交互：按住图片可以直接拖拽调整重点位置；双击某张图可以手动替换图源；在灰色画布按 Ctrl + 滚轮 可以全局缩放。

### 批量生成：调好后，直接点击 [🚀 自动对左侧【所有】文件夹生成]，一键挂机出图。

## 🖥️ 全局运行日志监控
遇到发种失败？图床报错？不要慌。
切换到 【🖥️ 运行日志监控】 标签页，这里记录了程序自启动以来的所有蛛丝马迹，包含接口状态码和报错详情。无论是反馈 Bug 还是排查网络问题，这里都是最强辅助。

## ❓ 常见问题 (FAQ)
### Q: 为什么提示我 Cookie 失效？
### A: PT 站的 Cookie 是有时效的（或者你的 IP 发生了变动）。请重新在浏览器登录 PT 站，按 F12 抓取最新的 Cookie 并在偏好设置中更新。

### Q: 为什么推送到 qBittorrent 失败？
### A: 请检查你的 qB 是否开启了 WebUI 功能，并且端口号、账号密码是否与“偏好设置”中填写的一致。如果不使用本地 qB 而使用群晖 NAS 等远程 qB，请确保 IP 地址正确且网络互通。

### Q: 自动扫描时文件变少了？
### A: 程序内置了广告拦截器。如果你在偏好设置里配置了删除 .txt、.url 或带有“赌场”字样的文件，程序在扫描时会为了保护你的账号安全，自动删除这些“毒药”文件。
